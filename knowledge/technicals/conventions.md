# Technical conventions used in pitches/trades

## Support/resistance
- Prior swing highs/lows over 20-60 day window
- Round numbers as psychological anchors
- Prior gap edges

## ATR sizing
- SL placed beyond 1.5x ATR(14) is the default "meaningful move" threshold
- TP set at ≥2x SL distance for `risk_reward=1` rubric factor
