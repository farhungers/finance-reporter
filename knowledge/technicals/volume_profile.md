# Volume profile: POC, VAH, VAL

## Core rule
Price migrates toward high-volume nodes (magnets) and rejects from low-volume gaps (rejection zones). Point of Control (POC) — the price at which most volume traded — is the single most important reference level within a session or profile window.

## Base rates
- Balanced sessions (normal-distribution profile): price returns to POC ~65-75% of the time within the session.
- Value Area (VAH/VAL, 70% of session volume) contains subsequent-day price ~55-65% of the time in balanced regimes.
- Low-volume nodes (LVN) between two high-volume nodes get traversed quickly — price rarely lingers.
- Prior-day POC is a top-tier next-day reference — first-touch reaction rate ~60%.
- Composite (multi-week) profiles produce more stable levels than single-session profiles.

## When it works
- Range-bound / balanced markets where auction theory applies cleanly.
- Liquid futures (ES, NQ, CL, GC), liquid equity indices, top-cap crypto with continuous 24h tape.
- Multi-timeframe confluence — session POC aligned with weekly volume node is a strong level.
- Post-consolidation setups — the value area defines the range, breakout targets sit at prior profile edges.

## When it fails
- News-driven gap opens — profile from prior session is invalidated; price is discovering new value.
- Trending days (elongated profile, no return-to-POC) — trend-following rules dominate over profile mean reversion.
- Illiquid instruments — profile is dominated by a handful of large prints, not real auction.
- After regime shifts (rate cycle turn, earnings guidance shock) — old value areas stop mattering.

## Application
- TP hint for mean-reversion trades: prior-session POC as the first magnet.
- SL hint for breakout trades: 0.5× ATR beyond the value-area boundary (VAH for longs, VAL for shorts).
- Entry hint in pitches: "near VAL of last week's profile" is a defensible entry reference for a long.
- Avoid volume-profile references on the day of a scheduled catalyst — profile-based logic breaks around news.
